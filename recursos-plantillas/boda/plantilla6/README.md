# Olivo y lino

Recursos proporcionados por el propietario para el octavo diseño de boda. Se conservan las imágenes originales, incluida la transparencia de los PNG.

| Archivo de origen | Archivo para sincronización | Uso |
| --- | --- | --- |
| Superior izquierdo olivo.png | Superior_izquierdo.png | Esquina superior izquierda |
| Inferior derecho olivo.png | Inferior_derecho.png | Esquina inferior derecha |
| ramaolivopng.png | flor.png | Rama de bienvenida |
| decorateolivopng.png | decorate.png | Mariposa y adornos pequeños |
| textura.jpg | textura.jpg | Fondo de lino |

Ejecutar `npm run templates:sync` para publicar las copias. El diseño cerrado tiene el identificador `wedding-olive-v1`; `plantilla6` identifica su colección de imágenes.
