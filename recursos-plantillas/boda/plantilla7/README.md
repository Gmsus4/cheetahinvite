# Costa mediterránea

Recursos originales proporcionados por el propietario para el noveno diseño de boda. Los PNG conservan su transparencia y resolución originales.

| Archivo de origen | Archivo para sincronización | Uso |
| --- | --- | --- |
| limonesquinapng.png | Superior_izquierdo.png | Limones en la esquina inferior izquierda de portada |
| esquinaazulejo.png | Inferior_derecho.png | Esquina de cerámica, girada en la portada |
| decoratelimon.png | flor.png | Limones de bienvenida y pie de página |
| decoracionazulejo.png | decorate.png | Ornamento cerámico de portada y capítulos |
| azulejos.jpg | textura.jpg | Detalles laterales y marco de la fotografía, sin cubrir textos |

Ejecutar `npm run templates:sync` para publicar las copias. El diseño cerrado es `wedding-mediterranean-v1`; `plantilla7` identifica la colección de imágenes. El patrón de azulejos se reserva para marcos decorativos; no se usa como textura general ni como franja entre capítulos.
